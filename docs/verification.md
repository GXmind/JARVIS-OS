## 拙政园导航停顿修复

真实 PlaceSearch 同时返回“拙政园”景区与同名热点地名。旧版按数字类型编码打分，未识别 SDK 的中文类型，两者并列后静默等待选择。

现同时识别中文类别和数字 typecode，准确景区优先于泛地名；多个真实同类景区仍要求确认。等待选择时退出加载状态，并在中央持续提示左侧选择，防止后端旧字幕盖住提示。失败会显示具体原因和重试指引，本机请求设置明确超时。

带“给我路线”“给我导航路线”等尾句不会污染目的地名称。实际“帮我导航到拙政园”已通过真实服务验证：选中苏州东北街178号景区，返回四种交通方案，三维城市完成展开。

新增回归覆盖 SDK 中文类别、真实同名景区歧义、候选选择后继续、取消等待、旧字幕覆盖及错误反馈。私人起点、路线截图和本机日志不提交。
