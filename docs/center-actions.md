# 自由提示词与中心粒子交互

本轮在 `feature/expand-center-screen-actions` 开发；前一轮地图手势与唤醒通过 PR #3 合入 main。

## 自由绘制

按 **F4** 打开已有输入栏的“自由绘制”模式，直接描述要绘制的内容，不要求固定对象名称或固定句式。例如：

- 紫色星河中的蓝色鲸鱼，尾巴朝右，上方三颗金色五角星。
- 一座有悬浮平台、拱形桥和发光窗户的未来城市，镜头缓慢环绕。
- 三维蝴蝶，翅膀展开并缓慢摆动，身体保持不动。

Enter 仍是普通对话入口。语音或普通输入也可说“画一幅……”“帮我建模……”“生成……动画”。已有图景时，可继续说“把鲸鱼身体改成蓝色，尾巴保持粉色”“给它加一双弯曲的翅膀”。描述性编辑会带上当前场景，保留未要求修改的细节；不会被简化成给所有构件统一改色。

配置云端后，**所有创建请求都交给模型处理完整提示词**，即使主体是汽车、火箭等已知对象，也不会优先套用内置造型。输入长度支持 1–20000 字，实际效果取决于配置模型生成绘制描述的能力。这里生成的是自由粒子图景和概念模型，不是照片级生图服务或精密 CAD 导出。

没有云端配置时，仅提供明确标注的内置离线演示；未支持的离线题材会提示配置 API。演示不能代表任意提示词已经完成。

## 交互与动画

- 拖动中心模型旋转，滚轮缩放，双击复位。
- “暂停动画”“恢复动画”“快一点”“慢一点”“散开”“重新汇聚”提供简单整体控制。
- 带部位、颜色、构图和多重要求的输入交由模型重新设计，不用整体快捷动作吞掉细节。
- 模型可为构件生成独立的移动、旋转、缩放关键帧，并指定翅根、尾根等铰点。暂停冻结动画时间；手动观察仍可操作。
- **Esc** 关闭模型或取消待生成图景；再次使用普通退出流程关闭应用。

地图、图景与对话有独立表现优先级：地图和粒子模型展示时保持专门形态。新的主屏导航收起主屏图景；已经传送的副屏地图不受影响。

## 绘制描述与渲染

模型只返回 JSON 数据，不返回可执行程序。协议支持：

| 类型 | 用途 |
| --- | --- |
| drawing | 任意 SVG 路径构成的轮廓、填色、内部细节与构图 |
| curve | 空间曲线与管状轮廓、枝条、触须 |
| patch | 2–8 行 × 2–8 列控制点组成的自由 Bezier 曲面 |
| mesh | 自定义顶点和三角面 |
| lathe | 自由剖面旋转曲面 |
| sphere/box 等 | 构图的基础构件或离线演示辅助 |

路径仅接受 M/L/H/V/C/S/Q/T/A/Z 的数据，不加载 SVG 文档、脚本、网页、外部图片或远程资源。支持任意十六进制颜色。场景构件、路径长度、坐标、网格和关键帧都有预算；正常约 20000 粒子，节能约 12000，硬上限 24000，避免弱电脑无界采样。

后台 Worker 采样自由路径和曲面，按可见面积分配粒子，主线程复用同一组 GPU 缓冲。场景没有变化时状态轮询不反复发送完整几何。协议无效时最多修正一次，不偷偷改成预设；实际渲染失败会说明原因并回到能量体。

## 形态与颜色

待机为缓慢交织的星云，聆听展开为受输入音量影响的环带；语音辨识、思考、回应和构形各有不同的运动结构。转变会平滑过渡。中心主色改为靛蓝、紫、玫瑰色和星光白，界面布局及两侧状态栏保持原结构。

## 更连续的语音

`CHAT_STREAM=true` 时逐段接收模型文字，按自然分句提前合成。Windows 系统语音引擎在启动阶段预热并复用，最多两个在途合成任务，整次回复共用一个 PCM 输出设备，避免句间反复打开设备。字幕依据实际播放样本进度换行。取消请求会释放底层连接，不等待整段生成结束。

F2 中可分别设置对话回应速度和绘制思考强度。对 DeepSeek 官方支持模型，默认日常对话使用快速回应；绘制默认使用平衡模式，也可选速度优先或更深入设计。其他兼容服务维持自身参数，不接收 DeepSeek 专用字段。依据：[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[流式接口](https://api-docs.deepseek.com/api/create-chat-completion/)。

语音识别仍使用独立 ASR；网络、服务商排队和音频设备会影响总时延，本轮未加入全双工无缝对话。系统播报质量仍需人耳确认。

## 待机持续运动

无任务、无录音时，核心仍随渲染时钟呼吸（周期约5.2秒，缩放幅度约±4.5%）并缓慢摆转，原有纤维与粒子继续流动。该运动不依赖语音振幅；思考/对话、地图和自由模型通过各自的状态过渡接管中心。隐藏主窗口仍暂停绘制以减少负载。check_center.py 在实际 Chromium 中核对无任务下帧数、呼吸尺度与朝向持续改变。
