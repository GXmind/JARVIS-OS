# 地图精度、楼高与全向查看

分支：feature/map-update。默认普通窗口，保留两侧现有状态栏与中央能量体的双向粒子过渡。

## 细节与精度

街区默认显示尺度从 2600 米收近到 1600 米；支持在 F2 设置 600–5000 米，下次导航生效。地图源提供的坐标与高德路线没有人为平移或“贴线”修改。

MVT 多边形按外环和内环分组，内院不再变成额外楼房；建筑部件保留底部高度，标记 hide_3d 的重复外轮廓不重复生成塔楼。相同瓦片几何去重，并在实际请求范围内筛选，再限制预算，避免远处数据占满近景额度。道路区分主路、支路与步道，并显示有限数量的真实道路名。

局部矢量预算提升至最多 3600 建筑部件、4000 道路要素；源瓦片仍最多九块、四个并发。解码后的坐标不做低精度取整。路线粒子间隔约 2 米，增加视觉连续性，不代表原始导航线路的测绘精度增加。

OpenFreeMap 此数据源最高为 z14，本分支没有伪称请求 z16/z18 精度。缺失数据仍受源覆盖限制，部分瓦片下载失败会注明覆盖不完整。MVT 外环、内环规则见 [官方规范](https://github.com/mapbox/vector-tile-spec/blob/master/2.1/README.md)，建筑字段见 [OpenMapTiles schema](https://openmaptiles.org/docs/schema/)。

## 楼宇高度

默认视觉高度强调从 ×8 改为 ×16，结合更近的街区尺度增强立体感。中央高度滑块可实时调节 ×1–×32；F2 的 MAP_HEIGHT_SCALE 决定下次导航默认值。高楼视觉高度有屏幕适配上限。

原始 height / min_height 保留在地理数据中，滑块只缩放建筑渲染组，不会修改数据源高度，不影响路线及道路坐标，也不重建整套粒子。近似或估计高度仍明确标注，不能当作实测楼高。

## 操作

| 操作 | 手势 |
| --- | --- |
| 水平环绕 | 左键横向拖动，可连续超过 360 度 |
| 俯仰查看 | 左键纵向拖动，在近水平与俯视之间调整 |
| 平移 | 右键拖动，或 Shift + 左键拖动 |
| 缩放 | 滚轮；触屏双指捏合 |
| 触屏查看 | 单指环绕/俯仰，双指捏合和平移 |
| 复位 | 双击中央，或点击“视角复位” |
| 楼高强调 | 中央高度滑块 |

水平角度不锁定；俯仰限制为安全观看角度，避免翻到地下。复位恢复角度、平移和缩放，保留当前高度强调值。

## 验证

111 项 Python 单元测试、Node 几何/手势/地点测试及 Chromium 实际 WebGL 回归通过。实际高德至拙政园联调完成：真实鼠标拖动超过 1.6 圈、纵向俯仰、右键平移、滚轮缩放、双击复位，以及 ×16 到 ×24 的高度调节。触屏双指事件由回归用例验证，未声称在物理触屏硬件上测试。
