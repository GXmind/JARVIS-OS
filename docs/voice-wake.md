# Hi Jarvis 唤醒与一轮语音指令

在普通主窗口待机时说 **“Hi Jarvis”**，等提示音和“我在，请说您的指令”，再说中文指令；停顿约 1 秒会自动结束录音，调用 F2 中配置的 ASR，再交给导航或对话流程。完成回复后回到唤醒待机。本版是一轮唤醒一条指令，尚无打断播报的无缝连续对话。

## 安装

先运行 start.cmd 建立 F:\Javis_os 内的环境，再双击 scripts/install_wake.cmd。安装 Vosk 0.3.45 和约 40 MB 的 vosk-model-small-en-us-0.15。下载使用固定版本、完整 SHA-256 校验及有界重试；模型、压缩包、pip 缓存和临时文件均保存在根目录。开源组件许可证见 THIRD_PARTY_NOTICES.md。

本机已安装时直接重新启动。没有组件时界面显示安装提示，手动输入和 F8 仍可用。F10 或麦克风上方唤醒文字可开关；F2 也可配置开关、等待时限（默认 8 秒）和句末静音（默认 1 秒）。输入设备沿用 F2 的麦克风选择。副屏无录音或唤醒权限。

## 能力边界

Vosk 只在本机识别英文唤醒短语，包括 hi/high 的同音形式，不承担中文指令转写。中文 ASR 仍使用独立的语音识别 API，聊天模型和 TTS 互相独立。若未配置 ASR，唤醒后会提示 F2，不发送空录音。

待机 PCM 不保存、不上传。唤醒成功后先关闭关键词监听，释放同一把音频锁，播放提示，再等待指令；仅这段指令按原录音策略存入 recordings 并发送已配置 ASR。没听到人声则丢弃空文件并回到待机。回复和手动操作期间暂停唤醒，避免助手播报触发自身。

音量阈值和停顿检测属于第一版规则。噪声、远距离、口音及长停顿需要现场验收，可适当调高句末静音。不是训练出的专用唤醒神经网络，也没有承诺固定误唤醒率。

## 验证

```powershell
.\.venv\Scripts\python.exe -B scripts\check_wake.py
.\.venv\Scripts\python.exe -B scripts\check_wake.py --microphone
```

脚本使用系统生成的英语测试音频直接送给真实离线解码器，不向房间播放，也不调用云端；第二条额外检查真实麦克风启动、暂停后释放音频锁及线程关闭，不保存环境音。此测试不能代替真人唤醒准确率或完整云端 ASR 听感验收。报告留在 logs/wake_runtime_check.json。
